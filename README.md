# SauceDemo QA Assessment Framework

This project provides a Playwright TypeScript framework for SauceDemo automation and the assessment tasks.

## Setup

```bash
npm install
npx playwright install chromium
```

## Run tests

```bash
npx playwright test
```

## Run tests headed

```bash
npx playwright test --headed
```

## Show report

```bash
npx playwright show-report
```
